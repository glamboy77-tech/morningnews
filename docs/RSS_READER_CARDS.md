# 기사 미리보기 카드

- 첫 화면과 펼쳐서 보는 기사 목록에 RSS `description`의 텍스트를 최대 145자로 표시합니다. 너무 짧거나 제목만 반복하는 설명은 표시하지 않습니다. AI가 새로 작성한 요약이 아니라 **RSS 제공 미리보기**입니다.
- RSS의 `media:thumbnail`, 이미지 첨부 파일, 설명 안의 이미지 주소를 수집해 `image_url`로 보존합니다. 과거 캐시에 이미지 필드가 없어도 설명에 들어 있는 이미지를 읽을 수 있습니다.
- 기사 사진은 기본값으로 **켜져 있습니다.** RSS에 포함된 이미지 주소만 사용하며 기사 페이지를 별도로 긁거나 이미지를 서버에 저장하지 않습니다. HTTPS JPG/PNG/WebP 주소만 표시하며, 이미지가 없는 카드는 기존 카테고리 그림 또는 텍스트 카드를 사용합니다.
- 사진을 다시 끄려면 실행 환경에 다음을 설정한 뒤 페이지를 다시 생성하세요:

  ```text
  MORNINGNEWS_IMAGES=off
  ```

  공개 GitHub Pages에 게시된 페이지는 개인용으로 만든 것이더라도 외부에 공개됩니다. RSS에 이미지 URL이 있다는 사실 자체가 재게시 허가를 뜻하지는 않습니다. 브라우저가 이미지 호스트에 직접 접속하므로 방문 정보가 전달될 수 있고 사진이 차단되거나 삭제될 수도 있습니다. 이미지 로딩에 실패해도 기사 링크와 미리보기는 유지됩니다.
