# 기사 미리보기 카드

- 첫 화면과 펼쳐서 보는 기사 목록에 RSS `description`의 텍스트를 최대 145자로 표시합니다. 너무 짧거나 제목만 반복하는 설명은 표시하지 않습니다. AI가 새로 작성한 요약이 아니라 **RSS 제공 미리보기**입니다.
- RSS의 `media:thumbnail`, 이미지 첨부 파일, 설명 안의 이미지 주소를 수집해 `image_url`로 보존합니다. 과거 캐시에 이미지 필드가 없어도 설명에 들어 있는 이미지를 읽을 수 있습니다.
- 기사 사진은 기본값으로 **꺼져 있습니다.** RSS에 사진 URL이 있다는 사실만으로 공개 페이지 재사용 권한이 주어지는 것은 아니므로, 출처별 이용 조건을 확인한 뒤에만 허용하세요. 허용 전에는 첫 화면에 자체 제작된 카테고리 그림만 보입니다.
- 허용이 확인된 출처가 있으면 실행 환경에 다음을 설정할 수 있습니다(값은 실제 허용된 출처/이미지 호스트로 교체):

  ```text
  MORNINGNEWS_IMAGE_SOURCES=허용된 RSS 출처명
  MORNINGNEWS_IMAGE_HOSTS=허용된 이미지 호스트명
  ```

  두 값이 모두 맞고 URL이 HTTPS JPG/PNG/WebP일 때만 사진이 표시됩니다. 여러 값은 쉼표로 구분합니다. 공개 페이지를 다시 생성해야 설정이 반영됩니다. 브라우저가 외부 이미지를 직접 불러오므로 해당 호스트에 방문 정보가 전달될 수 있고, 사진이 차단되거나 삭제될 수도 있습니다. 사진이 표시되지 않더라도 기사 링크와 미리보기는 유지됩니다.
